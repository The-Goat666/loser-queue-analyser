# Loser Queue Analyser

A statistical analysis tool for ranked League of Legends players.

## What it does
Analyses match history for any given player and computes aggregated team-level and individual statistics across hundreds of games, including:
- Team K/D differentials
- Gold differences at 15 minutes
- Objective control (dragons, barons)
- Phase-by-phase K/D/A breakdowns (early/mid/late)
- Damage and mitigation comparisons
- Individual performance vs opponent in the same role

The goal is to help players determine whether their ranked outcomes correlate with their own performance or team-level factors outside their control.

## APIs used
- Match v5
- League v4
- Summoner v4

## Usage
Add your PUUID and API key to the script and run locally with Python.
